## 一、关闭确认功能（✅ 已实施）

在 `TrestleUI` 中实现了基于数据快照对比的关闭确认：

1. **`_capture_saved_snapshot()`**：`__init__` 末尾 + `save_params` 成功后调用，深拷贝 `projects_dict`
2. **`_on_closing()`**：`WM_DELETE_WINDOW` 协议 + "退出"按钮均调用
3. **`_dicts_equal()`**：递归比较两个 dict 结构

```
_on_closing:
  1. _force_refresh_all_caches() + combine_all_summary() → 写回 projects_dict
  2. _dicts_equal(projects_dict, _saved_snapshot) ?
     - 相等 → root.destroy()
     - 不等 → askyesnocancel("未保存的修改", "是否保存后再关闭？")
       - 是 → save_params() 成功 → root.destroy()
       - 是 → save_params() 失败 → 不关闭（已弹错误提示）
       - 否 → root.destroy()
       - 取消 → return
```

## 二、数据验证功能（✅ 已实施）

### 2.1 验证时机与范围

| 验证点 | 触发时机 | 验证对象 | 说明 |
|--------|---------|---------|------|
| **MCT 生成** | 点击"生成 MCT"时 | 当前项目 cache | 报错不带项目前缀 |
| **保存参数** | 点击"保存参数"时 | `projects_dict` 全部项目 | 报错带 `[项目名编号]` 前缀 |
| **二级窗口保存** | 下部结构/截面参数等二级窗口点击"保存"时 | Entry 控件值 | 待实施 |

### 2.2 验证原则

- **不强制正值**：只判断"有内容且是数值"
- **特殊格式需解析验证**：计算跨径、各种布置间距等需实际解析（`_parse_simple_spacing`）
- **按 Tab 顺序报错**

### 2.3 检查项总览

验证函数 `_validate_project(proj)` 按 Tab 顺序分组验证：

#### 基本参数（`proj["basic"]`）→ `_validate_basic`

| # | 键 | 验证规则 | 说明 |
|---|-----|---------|------|
| 1 | `span` | 非空 + 间距格式可解析 | 如 "12,15,12" 或 "2@1500" |
| 2 | `bridge_width` | 非空 + 数值 | |
| 3 | `water_level` | 数值（非空时） | 支持 "+12" 格式 |
| 4 | `deck_level` | 数值（非空时） | 支持 "+12" 格式 |
| 5 | `deck_level` > `water_level` | 桥面高程须高于设防水位 | 两者均有值时检查 |

> `span` 和 `bridge_width` 在失焦时即时验证（`_on_span_width_change`）。

#### 上部结构（`proj["components"][桥型]`）→ `_validate_components`

| # | 键 | 验证规则 | 说明 |
|---|-----|---------|------|
| 3 | `rib_trans_space` | 非空 + 间距格式可解析 | 横肋间距 |

### 2.4 验证流程

```
save_params():  # 保存参数 — 验证全项目
    _force_refresh_all_caches()
    current = combine_all_summary()
    projects_dict[current_key] = current
    errors = []
    for key, proj in projects_dict.items():
        pname = proj["project_name"] + proj["project_no"]
        proj_errors = _validate_project(proj)
        errors.extend([f"[{pname}] {e}" for e in proj_errors])
    if errors:
        messagebox.showwarning(...)
        return False
    # 原有保存逻辑 ...

_run_mct():  # 生成 MCT — 验证当前项目
    _force_refresh_all_caches()
    summary = combine_all_summary()
    errors = _validate_project(summary)
    if errors:
        messagebox.showwarning(...)
        return
    # 原有生成逻辑 ...

_validate_project(proj: dict) -> list[str]:
    errors = []
    errors += _validate_basic(proj.get("basic", {}))
    errors += _validate_components(proj.get("components", {}))
    errors += _validate_environment(proj.get("environment", {}))
    errors += _validate_vehicles(proj.get("vehicle", {}))
    errors += _validate_load_cases(proj)
    errors += _validate_loadcombs(proj)
    return errors
```

## 三、已实施变更记录

### 2026-08-31：关闭确认 + 数据验证

**新增方法（`TrestleUI` 类内）：**

| 方法 | 作用 |
|------|------|
| `_capture_saved_snapshot()` | 深拷贝 `projects_dict` 到 `_saved_snapshot` |
| `_dicts_equal(a, b)` | 递归比较 dict/list/primitive |
| `_on_closing()` | 对比快照 → askyesnocancel → 保存/丢弃/取消 |
| `_is_numeric(val)` | 判断是否为有效数值 |
| `_is_dist_format(val)` | 判断是否为间距格式（`_parse_simple_spacing` 解析） |
| `_validate_project(proj)` | 主验证入口，调用以下6个分项函数 |
| `_validate_basic(basic)` | 基本参数验证（span 间距格式 + bridge_width 数值） |
| `_validate_components(components)` | 上部结构验证（间距格式 + 数值 + 条件必填） |
| `_validate_environment(env)` | 环境荷载验证（wind/water 数值） |
| `_validate_vehicles(vehicle)` | 车辆参数验证（一般车辆距前轴/轴重解析 + 非一般车辆数值 + 重名检查） |
| `_validate_load_cases(proj)` | 移动/静载工况车辆引用验证 |
| `_validate_loadcombs(proj)` | 荷载组合系数验证（gamma/psi 为 float） |

**调用点：**

| 位置 | 改动 |
|------|------|
| `__init__` 末尾 | `_force_refresh_all_caches()` + `combine_all_summary()` + `_capture_saved_snapshot()` |
| `save_params` | 遍历 `projects_dict` 全项目验证，报错带 `[项目名编号]` 前缀 |
| `save_params` 成功后 | `self._capture_saved_snapshot()` |
| `_run_mct` | 验证当前项目 |
| "退出"按钮 | `command=self._on_closing`（原 `self.root.destroy`） |
| 入口函数 | `root.protocol("WM_DELETE_WINDOW", app._on_closing)` |
